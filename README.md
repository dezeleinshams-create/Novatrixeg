# منصة نوفاتريكس إي جي التقنية | Novatrix EG Portal

موقع ويب تفاعلي حديث ومتكامل لصناع المحتوى التقني باللغة العربية. يدمج الموقع بين طابع **موقع البايو والروابط السريعة (Link-in-bio)** مثل Linkfly، و**موقع شروحات وتنزيل التطبيقات** مثل Techs4Arab، بالإضافة إلى **مكتبة ذكية مخصصة لأوامر الذكاء الاصطناعي (AI Prompts)**.

---

## 🚀 ميزات المنصة الرئيسية

1. **شريط روابط التواصل التفاعلي (Social Ribbon)**:
   - يضم 5 منصات رئيسية (فيسبوك، تليجرام، يوتيوب، تيك توك، إنستغرام) بتنسيق شبكي مرن يدعم التجاوب وحركات نيون مخصصة لكل منصة.
2. **مستكشف البدائل المجانية (Alternative Finder)**:
   - أداة بحث تتيح للجمهور العثور فوراً على البدائل المجانية ومفتوحة المصدر لأشهر البرامج المدفوعة (مثل Photoshop, Office, Canva) مع وصف بالعربي للبدائل وروابط تحميلها.
3. **مستشار أمان الهاتف (Security Checkup)**:
   - اختبار تفاعلي من 4 أسئلة لفحص أمان الهاتف وحساب النسبة الإجمالية للأمان مع مؤشر قياس نيون وعرض قائمة نصائح إغلاق الثغرات.
4. **مساعد الدعم التقني الذكي (AI Tech Bot)**:
   - نظام دردشة (Chatbot) محاكي يتيح للزوار طرح أسئلة تقنية أو اختيار أسئلة شائعة (حماية الواتساب، علامات الاختراق، استرجاع الصور) وتلقي إجابات ذكية فورية مع تأثير جاري الكتابة.
5. **مكتبة أوامر الذكاء الاصطناعي الشاملة (+1000 برومت)**:
   - صفحة ثانية مستقلة تحتوي على:
     - **مخصّص الأوامر التفاعلي (Dynamic Customizer)**: يولد مئات التركيبات الفريدة للأوامر بمجرد تحديد الفئة والموضوع والأسلوب.
     - **قاعدة بيانات برومبتات مشروحة بالعربي**: كروت برومبتات مقسمة (صور، محتوى، برمجة) مع **شرح مفصل لكل أمر باللغة العربية** وزر نسخ سريع.
     - **تصفح مرن**: يدعم البحث الفوري والفلترة والترقيم (Pagination).
6. **شبكة التطبيقات ومؤقت التحميل الآمن**:
   - دليل للتطبيقات والألعاب والحلول المقترحة مع ميزة البحث والتصفية.
   - نافذة تفاصيل منبثقة (Modal) تحتوي على مقارنة توفير مالي ومؤقت تنازلي دائري (10 ثوانٍ) لفحص أمان الرابط قبل إظهار زر التحميل المباشر.

## 🛠️ التقنيات المستخدمة

- **الهيكل**: HTML5 (بنية RTL متوافقة مع اللغة العربية).
- **التنسيق**: CSS3 (تأثيرات الزجاج Glassmorphism، متغيرات الألوان، تأثيرات النيون والحركات).
- **المنطق والتفاعل**: Vanilla JavaScript ES6 (قاعدة بيانات مدمجة، خوارزميات الفلترة، مؤقت تنازلي، نظام الدردشة ومولد البرومبتات).
- **الوسائط**: صور وشعارات مولدة بالذكاء الاصطناعي بجودة فائقة.

## 💻 التشغيل المحلي والمعاينة

لتشغيل الموقع ومعاينته على جهازك المحلي، اتبع الخطوات التالية:

### باستخدام Python (موصى به):
1. افتح مبدل الأوامر (Terminal) في مجلد المشروع.
2. اكتب الأمر التالي لبدء خادم ويب محلي:
   ```bash
   python -m http.server 8080
   ```
3. افتح متصفحك واذهب للرابط: `http://localhost:8080/`

## 🌐 النشر على الإنترنت (GitHub Pages)

يمكنك استضافة الموقع مجاناً وبسهولة على **GitHub Pages** ليكون متاحاً لجميع متابعيك على الإنترنت:

1. اذهب إلى مستودع المشروع على موقع جيت هاب: `https://github.com/dezeleinshams-create/abdallah-tech`
2. اضغط على التبويب **Settings** (الإعدادات) في القائمة العلوية.
3. من القائمة الجانبية اليسرى، اختر **Pages**.
4. تحت قسم **Build and deployment**:
   - اختر **Source**: `Deploy from a branch`.
   - تحت قسم **Branch**: اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
5. انتظر دقيقة واحدة، وسيعطيك جيت هاب رابطاً مباشراً لموقعك يكون بصيغة:
   `https://dezeleinshams-create.github.io/abdallah-tech/`
