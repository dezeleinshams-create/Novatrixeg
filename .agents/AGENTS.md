# قواعد العمل الخاصة بـ Novatrix EG

* **توفير التوكين (Token Saving)**: احرص دائماً على أن تكون الردود والمحادثات قصيرة وموجزة ومباشرة لتوفير التوكينز وتفادي استهلاك سياق المحادثة.
* **التنفيذ الخلفي (Background Execution)**: بالنسبة للمهام الكبيرة (مثل توليد محتوى ضخم، أو تعديل ملفات متعددة بشكل آلي)، قم بإنشاء سكربتات تشغيل (Python/PowerShell) وتشغيلها في الخلفية بدلاً من كتابة محتوياتها الضخمة داخل الشات.
* **دقة وقوة التنفيذ**: الحفاظ على أعلى مستويات الاحترافية والدقة البرمجية والجمالية للموقع وتفادي الاختصارات التي تخل بجودة الأكواد أو التصميم.
* **الالتزام الكامل بالسيو (SEO-First Development)**: أي صفحة أو أداة أو مقال يتم إضافته أو تعديله، يجب أن يُصاغ بعنوان ووصف مستهدف دلالياً لأسئلة المستخدمين في جوجل (مثل "ازاي"، "كيف"، "بديل")، مع تضمين أكواد Schema JSON-LD الهيكلية وتحديث خريطة الموقع `sitemap.xml` فوراً لضمان تصدر نتائج البحث.
